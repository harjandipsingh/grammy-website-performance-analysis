# Grammy.com Website Performance Analysis — Excel

An Excel-based analytics project evaluating whether splitting Grammy.com into two separate websites improved user engagement and conversion performance.

## Project Overview
Grammy.com previously hosted both Recording Academy content and Grammy Awards content on a single combined website. On February 1st, 2022, the company split this into two distinct sites.

**Core business question:** Did the website split actually improve how visitors engage with the content?

This project analyzes traffic and engagement data before and after the split, compares key performance metrics, and evaluates A/B test results to deliver a clear, evidence-based answer.

## Key Findings
- The split websites outperformed the combined site across all tracked engagement metrics
- Bounce rate decreased and pages per session increased post-split
- Average session duration improved post-split
- **CTA conversions increased by 23%** in A/B test results following the split
- Traffic spikes aligned with Grammy show nights, with additional lesser-known events also driving measurable increases

## Metrics Analyzed
- Visitors (total and mobile)
- Pageviews
- Sessions and bounce rate
- Pages per session
- Average session duration
- CTA (Call-to-Action) click results

## Tools Used
- Microsoft Excel
- Pivot tables and summary statistics
- Period-over-period metric comparison
- A/B test result evaluation
